# CERBER-ULTRA

**NULLXES Research Project for Computer Vision · YOLO26**

CERBER-ULTRA — исследовательский проект NULLXES по разработке системы компьютерного зрения для обработки видеопотока в реальном времени.

Цель проекта — создать собственный программный конвейер: от получения изображения и обнаружения объектов до отслеживания их состояния и анализа событий.

Проект находится на начальном этапе разработки. Базовое семейство моделей — **Ultralytics YOLO26**.

## Почему YOLO26

Основные критерии выбора — **скорость обработки, актуальность архитектуры и возможности локального развёртывания**.

* **Скорость.** YOLO26 поддерживает end-to-end инференс без отдельного этапа NMS. Облегчённая голова детектора снижает вычислительные накладные расходы.
* **Актуальность.** Семейство выпущено в 2026 году и представлено в текущей документации Ultralytics.
* **Масштабируемость.** Варианты `n`, `s`, `m`, `l`, `x` позволяют выбирать баланс между точностью и вычислительными затратами.
* **Развёртывание.** Поддерживается экспорт в ONNX, TensorRT и другие форматы для запуска на целевом оборудовании.

Техническая основа выбора: [официальная документация YOLO26](https://docs.ultralytics.com/models/yolo26/).

Конкретный размер модели и формат инференса будут выбраны по результатам локальных измерений. Производительность всей системы оценивается отдельно от скорости самой нейросети.

## Планируемые возможности

* Обнаружение объектов на изображениях и в видеопотоке.
* Отслеживание объектов между кадрами.
* Хранение краткосрочной истории сцены.
* Регистрация событий и сохранение результатов.
* Асинхронный анализ выбранных кадров и событий небольшой локальной моделью.
* Измерение задержки, точности и потребления ресурсов.

Подключение локальной модели планируется после получения рабочего CV-конвейера. Её обработка не должна блокировать поступление новых кадров.

## Быстрый старт: проверка YOLO26

Команды ниже запускают базовую модель через Ultralytics. Это проверка окружения перед разработкой CERBER-ULTRA.

### Установка

Рекомендуется использовать отдельное виртуальное окружение Python.

```bash
python -m pip install -U ultralytics
```

Для GPU-инференса сборка PyTorch должна соответствовать операционной системе и доступной версии CUDA.

### Запуск с веб-камеры

```bash
yolo predict model=yolo26n.pt source=0 show=True
```

### Обработка видео

Замените `path/to/video.mp4` на путь к своему файлу.

```bash
yolo predict model=yolo26n.pt source="path/to/video.mp4" save=True
```

Веса модели скачиваются автоматически при первом запуске. После загрузки весов инференс может выполняться локально.

Инструкция по настройке окружения: [Ultralytics Quickstart](https://docs.ultralytics.com/ru/quickstart).

## Оценка качества

Для каждого эксперимента фиксируются оборудование, версии зависимостей, веса модели, размер входного изображения и настройки инференса.

Основные метрики:

* FPS и сквозная задержка обработки, включая p50/p95.
* Precision, Recall и mAP на размеченной выборке.
* Количество переключений ID при трекинге.
* Потребление RAM и VRAM.
* Влияние локальной модели анализа на скорость CV-конвейера.

Результаты CERBER-ULTRA будут добавляться по мере проведения экспериментов.
